# meteologioco_shirinRahman

Brisa: aplicación meteorológica de Shirin Rahman, hecha con HTML, CSS y JavaScript.

## Página web

[Abrir Brisa](https://srahman25-ops.github.io/meteologioco_shirinRahman/)

## Funciones

- Búsqueda de ciudades y geolocalización.
- Temperatura, sensación térmica, humedad, viento y previsión por horas.
- Fondos de día y noche con sol, luna, nubes, lluvia, nieve, niebla y viento.
- Ciudades favoritas guardadas en el navegador.
- Diseño adaptable a móviles y movimiento reducido.

## Cómo abrir el proyecto

Descarga el repositorio y abre `index.html`. Necesitas conexión a Internet para consultar el tiempo. La geolocalización requiere HTTPS o localhost y permiso del navegador.

Para ejecutarlo en local, usa `python3 -m http.server 8000` dentro de la carpeta y abre http://localhost:8000.

## Archivos

- `index.html`: estructura de la aplicación.
- `meteo.css`: diseño y animaciones.
- `meteo.js`: consultas meteorológicas y gestión de favoritos.

Datos meteorológicos y búsqueda de ciudades: [Open-Meteo](https://open-meteo.com/).
